1. Open **Projects** in the sidebar.
2. Type a **New project name** and press **Add project**. It opens in the page editor.
3. Add the details, pictures and words, the same way as any page.
4. Press **Publish**. It appears at /work/your-project, and in the **Projects** block on any page.

![The Projects screen](shot:projects)

## Tips

- Use a **Gallery** or **Before and after** block to show the results.
