1. Open **Blog** in the sidebar and press **New post**.
2. Type the **Title** and write the post. Leave a blank line between paragraphs.
3. Open **Post settings** to add a **Cover image**, a short **Summary** and a **Category**.
4. Press **Publish now**.

![The Blog screen](shot:blog)

## Tips

- Start a line with “## ” for a heading and “- ” for a bullet point.
- Your latest posts can appear on any page with the **Latest posts** block.
